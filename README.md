# PoeClothes

Path of Exile 製作點擊保護（Windows）。

按住 Shift 連點做裝備時，PoeClothes 會讀取物品文字（Ctrl+C），一骰到你設定的詞綴就**鎖住左鍵**，避免手快把好裝備洗掉。

## 下載

到 [Releases](../../releases/latest) 下載 `PoeClothes.exe`（單一檔案，不用安裝，不需要 Node.js 或 VC++ 執行階段）。

## 功能

- 停止條件：依 poedb.tw 的基底資料挑詞綴，可指定前綴／後綴、最低階級、最低數值；前綴排在前、後綴排在後
- 方案：把一組條件存起來，「套用」切換、「儲存」覆蓋
- 骰到時左鍵鎖定，放開 Shift、按解除鍵（預設 F2）或按「解除鎖定」就能繼續；鎖定時仍可操作 PoeClothes 視窗
- 小視窗可保持在遊戲上層、調整透明度、精簡畫面、命中提示音

## 用法

1. 把 `PoeClothes.exe` 放在一個自己的資料夾（例如 `D:\PoeClothes`），雙擊開啟。
2. 在「停止條件」選基底、加條件、按「儲存條件」。
3. 在遊戲裡按住 Shift 點擊製作。

設定、poedb 資料和記錄會存在 exe 旁邊，所以不要放在 `C:\Program Files` 這類沒有寫入權限的資料夾。詳細說明見 Release 裡的 `README.txt`。

## 安全性

本程式**不讀取遊戲記憶體、不注入遊戲、不替你點擊**。它只按下複製鍵讀取剪貼簿裡的物品文字，並在命中時擋住你自己的左鍵。

## 系統需求

Windows 10 / 11（64 位元）。介面使用 Windows 內建的微軟正黑體。
